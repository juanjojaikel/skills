Este repositorio guarda **todo** el proyecto: planeación, decisiones, cada etapa de desarrollo con sus notas y, cuando
exista, el código. Está pensado para que cualquiera que entre después pueda ver cómo se hizo cada cosa y por qué.

## Por dónde empezar

1. `ESTADO.md` — dónde va el proyecto hoy, el siguiente paso y los pendientes.
2. `00. Planeacion/07-vision-producto/vision-producto.html` — qué es el producto y por qué (fuente de verdad).
3. `00. Planeacion/07-vision-producto/hoja-de-ruta.html` — las etapas, qué se hace en cada una y con qué herramientas.
4. `DECISIONES.md` — todas las decisiones, en orden, con su porqué.
5. `CLAUDE.md` — las reglas de trabajo (se cargan solas en cada sesión de Claude Code).

Para operar el repositorio hacen falta `git`, Node 18 o más nuevo y `gh` con sesión iniciada.
